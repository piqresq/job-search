# Job Board — Design System v3
**Single source of truth. Do not deviate without updating this file.**

## Aesthetic Anchor

**Otl Aicher / Dieter Rams / Braun precision tool — with an editorial display layer.**

A senior engineer's daily instrument: informative, hairline-driven, three deliberate type voices, one rare signal color. Atmosphere comes from typography rhythm and a faint engineering-paper grid — not from gradients, shadows, or decoration. The data is the hero.

> Inspired by Aicher's 1972 Munich pictogram system and Rams's "less but better."

## 2. Typography — Three Voices

### Font Loading

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="preconnect" href="https://api.fontshare.com">
<link href="https://api.fontshare.com/v2/css?f[]=switzer@400,500,600,700&display=swap" rel="stylesheet">
<link href="https://fonts.googleapis.com/css2?family=Instrument+Serif:ital@0;1&family=JetBrains+Mono:wght@400;500&display=swap" rel="stylesheet">
```

### Voice Table

| Voice | Family | Weights | Used for |
|-------|--------|---------|----------|
| **Display** | Instrument Serif (Google Fonts) | 400 + italic | Page titles, kanban column counts, empty-state hero copy |
| **UI / Body** | Switzer (Fontshare) | 400 / 500 / 600 / 700 | Everything else: nav, body, buttons, labels, card titles |
| **Tabular** | JetBrains Mono (Google Fonts) | 400 / 500 | Scores, dates, salary, IDs, countdowns, API params |

```css
--font-display: 'Instrument Serif', Georgia, serif;
--font-ui:      'Switzer', -apple-system, BlinkMacSystemFont, sans-serif;
--font-mono:    'JetBrains Mono', 'SF Mono', Menlo, monospace;
```

### Type Scale (1.2× modular ratio for UI; dramatic for display)

```css
--text-xs:       11px / 16px   /* tracking +0.04em UPPERCASE — LABEL, micro-caps */
--text-sm:       12px / 18px   /* meta, captions */
--text-md:       13px / 18px   /* UI default */
--text-base:     14px / 20px   /* body, list rows */
--text-lg:       16px / 24px   /* card titles */
--text-xl:       18px / 26px   /* section headers */
--text-2xl:      22px / 28px   /* page subtitles  tracking -0.01em */
--text-3xl:      28px / 34px   /* page titles (Switzer 600)  tracking -0.02em */
--display:       56px / 56px   /* Instrument Serif — column counts  tracking -0.025em */
--display-hero:  80px / 80px   /* Instrument Serif — empty-state  tracking -0.03em */
```

**Numbers everywhere:** `font-feature-settings: "tnum" 1, "lnum" 1` on all tabular-numeric data.
Never centered — always right-aligned in tables and columns.

### Border Radius

```css
--radius-xs:   4px    /* chips, vendor pills, selection box */
--radius-sm:   6px    /* score block, inputs, buttons, kanban card inner elements */
--radius-md:   10px   /* cards, sidebar nav items, popovers */
```

### Shadows

```css
--shadow-none:   none
--shadow-soft:   0 1px 2px rgba(11,11,15,0.04)                                        /* hover lift on cards */
--shadow-pop:    0 8px 24px -8px rgba(11,11,15,0.12), 0 2px 6px -2px rgba(11,11,15,0.08)  /* popover, dropdown */

```

**Hierarchy is hairline-driven by default.** `--shadow-soft` only appears on hover. Popovers and drawers are the only persistent shadows.

## 4. Motion

```css
--ease-out:    cubic-bezier(0.2, 0.8, 0.2, 1)   /* hover, press, fade-in */
--ease-in:     cubic-bezier(0.4, 0, 1, 1)        /* fade-out */
--ease-spring: cubic-bezier(0.16, 1, 0.3, 1)     /* drawer, modal, sheet */
--dur-fast:    120ms   /* color, opacity */
--dur-base:    180ms   /* hover, press, focus */
--dur-slow:    240ms   /* drawer, popover */
--dur-slower:  320ms   /* page transitions */
```

**Rules:**
- Animate `transform` and `opacity` only — never `width`, `height`, `top`, `left`
- Hover lift: `translateY(-1px)` + `border-color: --hairline-strong` + `box-shadow: --shadow-soft`. No scale.
- Press: `transform: translateY(0)` + slight color darken. No scale — keeps layout stable.
- Drawer: slide-in `translateX(16px → 0)` + fade `0 → 1` over 240ms ease-spring
- All animations wrapped in `@media (prefers-reduced-motion: reduce) { transition-duration: 0ms !important; }`
- "Generating…" pill: 1.4s shimmer (background-position only — no opacity flicker), looping until result
- Pipeline status dot: 2s breathing pulse (running state only) on `box-shadow: 0 0 0 0 → 0 0 0 6px brand-50` cycle

## 6. Atmosphere — Engineering Paper Grid

A 1px dot at every 16px intersection, behind inbox/board content.
**NOT behind sidebar, drawer, or modal.**

```css
.with-paper-grid {
  background-image: radial-gradient(circle at 1px 1px, rgba(11,11,15,0.06) 1px, transparent 0);
  background-size: 16px 16px;
  background-position: 0 0;
}
@media (max-width: 768px),
       (prefers-reduced-motion: reduce) and (prefers-contrast: more) {
  .with-paper-grid { background-image: none; }
}
```

This is the **only decoration** in the entire system. Everything else is content.

## 7. Components

### 7.1 Score Block (rectangular, never circular)

Three sizes. Square-ish (≈1.55:1 ratio). Tabular digit + optional decimal.

| Context | Size | Radius | Font |
|---------|------|--------|------|
| Inbox row (default) | 44 × 28px | 6px | 14px/700 tabular, 1px border |
| Kanban card | 40 × 26px | 6px | 13px/700 tabular, 1px border |
| Drawer hero | 64 × 44px | 8px | 22px/700 tabular, 1px border |

**Bands** (determine bg-tint, border, and digit color):

| Band | Threshold | bg | ink | border |
|------|-----------|-----|-----|--------|
| HIGH | ≥ 85 | `#DCFCE7` | `#14532D` | `#BBF7D0` |
| MEDIUM | 75–84 | `#FEF3C7` | `#78350F` | `#FDE68A` |
| LOW | 60–74 | `#F1F5F9` | `#334155` | `#E2E8F0` |
| FAILED | < 60 | `#FEE2E2` | `#7F1D1D` | `#FECACA` |

> Always paired with `aria-label="Score 8.7 of 10, high"` — never rely on color alone.

### 7.2 Kanban Column Header

Header is a stat block. Large serif numeral as architecture, hairline below, then cards.

- Padding: `20 24 16 24`
- `border-top: 3px solid var(--col-XXX)` (inside the wrapper)
- Below header: `1px solid var(--hairline)` divider, then card list with `gap: 12px`
- Column label: Switzer 11/600 uppercase, tracking +0.08em, ink-muted
- Count digit: Instrument Serif 56/400, tabular, ink-strong (Applying column: digit in `--col-applying`)
- `⊕` Add: icon-only ghost button, top-right, hover reveals

### 7.3 Kanban Card

Width 300–320px. Padding 14px. Radius 10px. Border 1px hairline. White surface.
Whole card is drag surface: `cursor: grab` / `cursor: grabbing`.

**Row 1:** 24px source logo (radius 4) + company name (Switzer 14/600, truncate) + score block (top-right)
**Row 2:** Job title (Switzer 14/500, line-clamp 2, hover tooltip for full)
**Hairline divider**
**Meta line:** Switzer 12/400 ink-muted, dates in JBMono, salary in JBMono, vendor chip
**Actions (column-dependent):** `[ Open ]` always; Applying adds `[ CV ↓ ] [ Cover ↓ ]` or "Generating…" pill

**States:**
- Idle: hairline border, white bg, no shadow
- Hover: border → hairline-strong, shadow-soft, `translateY(-1px)`
- Dragging: origin opacity 0.6; real card gets shadow-pop; drop targets get 2px brand-600 dashed outline
- Generating (Applying only): pill (24px tall, radius-pill, warning-50 bg, warning-800 text + spinning loader-2)
- Rejected countdown: `JBMono 11/500 warning-800` — "Auto-clears in 2d 14h" — no icon

### 7.4 Inbox Row

64–72px tall. Hairline divider between rows. Multi-select checkbox appears on hover or when any row is selected (then stays visible).

**Layout L→R:** `checkbox · 32×32 logo (radius 6) · company + title + meta · score block (44×28) · salary (JBMono) · vendor chip · [ Add to board ] · ⋯`

- Checkbox: 16×16, radius 4, hairline border, brand-600 fill when checked
- "Add to board": primary button (orange) — the only orange element on this row
- `⋯`: ghost icon button → menu (Open, Reject, Open URL)
- Click anywhere outside action area → opens detail drawer
- **Selected row:** bg = brand-50, left edge 3px brand-600 bar

### 7.5 Sidebar

232px wide, sticky left. Background: `--surface-sunken`.

- Right edge: `1px solid var(--hairline)`
- Nav item height: 36px, padding `0 16px`, radius 8
- **Hover:** bg = `--surface` (white pops from sunken band)
- **Active:** 3px brand-600 left bar inset + bg = `--surface` + ink-strong
- Counts: tabular numbers, right-aligned, ink-muted (JBMono 12/500)
- Pipeline status dot: 8px radius-pill; color reflects state (success / warning / danger / neutral)
- Sign out: ghost button, 12/500 ink-muted, danger-600 on hover

### 7.6 Header Bar

48px tall. White background. `1px solid var(--hairline)` bottom border. Sticky.

- Page title: Switzer 28/600 (NOT Instrument Serif — page titles use Switzer for legibility)
- Subtitle: 12/500 ink-muted, last-update time in JBMono
- Right: search input (flat, hairline border, 32px tall, 240px wide) + filter button

### 7.7 Buttons

All buttons: min 32px height (40px in inbox/kanban for touch targets), `cursor: pointer`, `transition: all var(--dur-base) var(--ease-out)`.

| Variant | bg | text | border | radius | padding | font |
|---------|----|----|--------|--------|---------|------|
| **PRIMARY** | `#FF5C28` | `#FFF` | none | 6px | 8×14 | 14/600 |
| **SECONDARY** | `#FFF` | `#0B0B0F` | 1px hairline | 6px | 8×14 | 14/500 |
| **GHOST** | transparent | `#2A2B33` | none | 6px | 8×12 | 14/500 |
| **DESTRUCTIVE** | `#FFF` | `#B91C1C` | 1px hairline | 6px | 8×14 | 14/500 |
| **ICON-ONLY** | transparent | — | none | 6px | — | — |

- PRIMARY hover: bg `#FF7A4A` · active: bg `#E84A18` · focus: 3px ring brand-50 + 1px brand-600
- SECONDARY hover: border hairline-strong + bg `#FAFAF7` · active: bg `#F4F3EE`
- GHOST hover: bg `#F4F3EE` · active: bg `#E8E6E1`
- DESTRUCTIVE hover: border `#FECACA` + bg `#FEE2E2`
- ICON-ONLY: 32×32px, hover bg `#F4F3EE`, always include `aria-label`

### 7.8 Inputs

**Text input:**
- Height: 32px (40px mobile), radius 6, padding `0 12`
- Border: 1px hairline, bg white, text 14/500, placeholder ink-faint
- Focus: border brand-600 + ring 3px brand-50 + `outline: none`
- Invalid: border danger-600 + helper text below in danger-600 12/500

**Controls:**
- Checkbox: 16×16, radius 4, hairline border, brand-600 fill when checked, white check icon
- Radio: 16×16, radius-pill, same color logic
- Toggle: 36×20 track, 16×16 knob; off = neutral-50 bg / hairline border; on = brand-600 bg
- Select: same as text input + caret-down icon, opens shadow-pop dropdown

### 7.9 Chips

**Filter chip (toolbar):**
- Height 28px, radius 6, padding `0 10`, border 1px hairline, bg white, 13/500
- With caret-down (popover trigger) or × (active removable filter)
- Active: bg brand-50, border brand-200, text brand-800

**Vendor mini-pill (in cards):**
- Height 18px, radius 4, padding `0 6`, text 11/600 uppercase tracking +0.04em
- bg = vendor tint, text = vendor full color (see Vendor Colors table)

**Country / meta chips:** NOT chips — inline text Switzer 12/400 ink-muted, separated by ` · ` mid-dot. Less is better.

### 7.10 Drawer (right slide-over)

Width: 480px (560px on ≥1440px). Full height. Slides from right, ease-spring 240ms.

**Sections (top → bottom):**
1. Header: source logo 24px + company name + close ×
2. Hairline
3. Hero score block (64×44) + recommendation band + label
4. Hairline
5. POSITION SUMMARY (11/600 caps) — 3 sentences, 14/400 ink-body, max 65ch
6. REASONS TO APPLY / RISKS — two-column on ≥560px
7. PIPELINE & EXTRACTION — collapsible (closed by default)
8. **Sticky footer:** `[ Open job ↗ ]` + `[ Apply ↗ ]` + "Move to ▾" column picker dropdown

- Backdrop: `--scrim` (45% black), clickable to dismiss
- Esc closes, focus returns to opening element
- First focusable element gets focus on open

### 7.11 Empty / Loading / Error States

**Empty:**
- Centered, vertical
- Instrument Serif 80px `—` (em-dash as hero — no icon)
- Switzer 14/500 ink-muted: "No jobs here yet."
- Switzer 13/400 ink-faint: contextual helper text
- No CTA in column-empty; CTA only at page-level empty

**Loading:**
- Skeleton rows (3-row stack): avatar block 32×32 (neutral-50, radius 6) + two text bars + score-block placeholder (44×28 neutral-50, radius 6)
- Shimmer: background-position sweep, 1.4s loop (no opacity flicker)

**Error:**
- Inline banner above affected list
- bg danger-50, border danger-200 1px, radius 8, padding `12 16`
- alert-triangle icon (Lucide 18px, danger-600) + 13/500 danger-800 text + "Retry" ghost button (right)

## 9. Accessibility Floor

All items below are **hard requirements**, enforced in every polish pass:

- All text ≥ 4.5:1 contrast against its surface (verified at token level — every fg/bg pair above passes)
- All interactive targets ≥ 44×44px hit area (icon buttons get padding even when visually 32×32)
- Visible focus ring on every focusable element — never removed (`--brand-600` 1px ring + `--brand-50` 3px halo)
- All icon-only buttons carry `aria-label`
- All score blocks carry `aria-label="Score X.X of 10, BAND"`
- Color is never the only signal — score has digit + band text; status uses dot + label; column has color + label + count
- Drag-and-drop has keyboard alternative: Space picks up, arrow keys move between columns, Space drops, Esc cancels
- `prefers-reduced-motion: reduce` disables dot-grid pulse and status-dot breathing
- Forms: visible labels above inputs (never placeholder-only); errors below the field; auto-focus first invalid field after submit
- `prefers-reduced-motion` also covered in the paper grid media query

## 10. The Non-Negotiable "No" List

| ❌ Forbidden |
|-------------|
| Purple, violet, indigo, magenta — anywhere |
| Gradient backgrounds (mesh, radial, linear — none) |
| Glass-morphism, backdrop-blur as decoration |
| Drop shadows by default (shadow-soft on hover only; shadow-pop popovers; shadow-drawer modal/drawer) |
| Emoji as icons or filler — Lucide only |
| Inter, Roboto, Arial, Fraunces, Geist, Space Grotesk |
| Left-border accent rounded cards (the AI cliché) |
| Fabricated stats, fake testimonials, fake logo walls |
| `scrollIntoView` (use `element.scrollTop` / `window.scrollTo`) |
| `const styles = {...}` global (collides across React components) |
| Animating `width` / `height` / `top` / `left` — transform/opacity only |
| Orange outside the Orange Budget table (§1) |

### Project Overrides (v3.md beats everything)

Even when skills say otherwise, the following **always apply** on this project:

- **Fonts:** Switzer + Instrument Serif + JetBrains Mono — never Inter, Geist, Space Grotesk, Roboto, Cabinet Grotesk, Satoshi, or Outfit.
- **No dark mode default** — this dashboard is light-mode (`--canvas: #FAFAF7`).
- **No gradients, no glass-morphism, no purple/violet/indigo** — even when skills suggest them.
- **Orange budget is strict** — `/bencium-innovative-ux-designer` and `/premium-frontend-design` use neon accent logic; on this project `--brand-600` (#FF5C28) is the one and only accent, used only as listed in §1.
- **Shadow discipline** — `/premium-frontend-design`'s glow/neon-shadow patterns do not apply; follow the v3.md shadow-by-exception rule.
- **Motion:** transform + opacity only; use v3.md duration tokens (`--dur-fast` 120ms … `--dur-slower` 320ms); `/design-taste-frontend` MOTION_INTENSITY is effectively level 4–5 for this product.
- **Animation workflow:** before changing animation behavior, load `/ui-animation`; before adding/changing motion tokens or reduced-motion behavior, load `/motion-scale`. Never use blanket reduced-motion overrides that shorten infinite loops without also replacing or disabling the loop.
